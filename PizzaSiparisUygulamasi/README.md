# 🍕 Java Swing Pizza Sipariş Uygulaması

Java Swing (`JFrame`) kütüphanesi kullanılarak geliştirilmiş; kullanıcıların hazır menülerden seçim yapabildiği, kendi pizzalarını sıfırdan oluşturabildiği ve sepet sistemine ürün ekleyebildiği kapsamlı masaüstü sipariş uygulaması.

## ✨ Özellikler

- **🍕 Hazır Menü Seçimi:** Önceden tanımlanmış özel pizza menüleri arasından hızlı seçim yapabilme.
- **🛠️ Kendi Pizzanı Oluştur:** Hamur tipi, boyutu ve malzemeleri (mantar, zeytin, mısır vb.) tamamen isteğe göre özelleştirme ekranı.
- **🍟 Ekstra Aparatifler & İçecekler:** Siparişe yan ürünler (patates kızartması, içecekler, soslar vb.) ekleyebilme.
- **🛒 Dinamik Sepet Sistemi:** Eklenen tüm pizza ve aparatların sepette listelenmesi ve anlık toplam tutar takibi.
- **📏 Boyut Seçenekleri:** Seçilen pizzaların boyutuna (Küçük, Orta, Büyük) göre fiyat güncellenmesi.

## 🛠️ Kullanılan Teknolojiler

- **Dil:** Java (JDK 8 veya üzeri)
- **Arayüz Framework:** Java Swing (`JFrame`, `JPanel`, `JButton`, `JCheckBox`, `JRadioButton`, `JList` / `JTable` vb.)
- **Geliştirme Ortamı:** NetBeans IDE

## ⚙️ Kurulum ve Çalıştırma

1. Proje dosyalarını ZIP'ten çıkarın veya indirin.
2. NetBeans IDE'yi açın ve `File > Open Project` adımlarını izleyerek projeyi seçin.
3. `AnaEkran.java` dosyasına sağ tıklayıp `Run File` (veya `Shift + F6`) seçeneği ile uygulamayı başlatın.
